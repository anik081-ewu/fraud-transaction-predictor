Rule thresholds

Adjust when each deterministic rule fires. The high-amount ratio must be lower than the extreme-amount ratio, and the 1-hour velocity threshold must be at least as high as the 10-minute one.

Reporting thresholdTotal below-threshold amount that triggers the structuring rule.
Structuring count (24 h)Min transactions below threshold in 24 h to flag structuring.
Rapid velocity (10 m)Transaction count in 10 minutes that triggers rapid velocity.
High velocity (1 h)Transaction count in 1 hour that triggers high velocity. Must be ≥ 10-minute threshold.
Multiple beneficiaries (1 h)Unique beneficiary count in 1 hour that triggers the rule.
Repeated amount (24 h)Identical-amount transaction count in 24 h that triggers the rule.
High amount ratioMultiplier vs 30-day average that flags a high-amount transaction.
Extreme amount ratioMultiplier vs 30-day average that flags an extreme-amount transaction. Must exceed high ratio.
High balance ratioTransaction-to-balance fraction that triggers the high-balance rule (0–1).
Expected turnover ratioTransaction-to-monthly-turnover fraction that triggers the turnover rule (0–1).
One or more thresholds are invalid — check ratios and counts.
