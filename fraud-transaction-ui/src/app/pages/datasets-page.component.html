How to use this page

Each column shows the best available model for that type CHAMPION takes precedence over CANDIDATE. Enable models in the Risk Policy page to include their anomaly scores in the live fraud decision. Training is done from Training Operations this page always reflects the current registry state.

Comparing fairly: EM-AUC is the metric to rank detectors on Excess-Mass AUC (Goix et al., 2016) measures how tightly a detector concentrates high scores, needs no fraud labels, and is scale-invariant, so it compares across model types. Score skewness, anomaly rate, alert count and learned rows are also comparable. Average and P95/P99 scores are not: each detector scores on its own scale, so a bigger number there does not mean a better model use them only across versions of one model type.

Not fraud accuracy. These are label-free diagnostics. Precision, recall and true false-positive rate stay unavailable until reviewers confirm outcomes in Case Management.

Reading the overlap

Jaccard is rows both models flagged divided by rows either flagged, so it is unaffected by one model simply flagging more than another. Near 1 means two models are nearly interchangeable; near 0 means they pick almost entirely different transactions.

Low overlap cuts both ways. It can mean the models are complementary, so an ensemble widens coverage or that each is latching onto different noise. A genuinely anomalous transaction would usually look anomalous to several detectors, so very few unanimous flags is worth investigating rather than celebrating.

Reading this table

Partitions are the oldest N% of the snapshot in chronological order, so each column is a genuine "how much history had we seen by then" point not a random sample. Rank detectors on EM-AUC; a rising curve means the detector keeps improving with more history, a flat one means it has saturated.

Two caveats. Cells marked capped sample hit a training-row limit, so they did not actually learn from the whole partition and are not like-for-like points on the curve. Detectors marked windowed (Half-Space Trees, Online One-Class SVM) forget older rows by design for them a declining curve reflects the rolling window, not a model getting worse with more data.
