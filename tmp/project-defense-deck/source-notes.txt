Communication job: By the end, the academic supervisor should understand that the project solves the label-scarcity, scalability, explainability, and governance problems of transaction monitoring with a dual-mode, four-layer architecture, while reporting measured limitations honestly.

Verified project evidence:
- 50,000-row unsupervised snapshot: Isolation Forest EM-AUC 67.2; Autoencoder 85.6; Behavioral Cluster Outlier 89.2.
- Fraud Detection Handbook adapted benchmark: 264,500 rows, 2,340 fraud rows (0.8847%), 749 customers, 183 days, chronological 70/10/20 split.
- Extra Trees untouched test result: PR-AUC 73.3%, precision 74.8%, recall 71.8%, F1 73.2%, TP 323, FP 109, FN 127, TN 52,341.
- 25,000-row integration snapshot: fusion did not materially outperform the strongest standalone classifier.
- Four-layer policy replay: precision 54.6%, recall 50.2%, F1 52.3%, balanced accuracy 74.1%; this is an explicit calibration limitation.
